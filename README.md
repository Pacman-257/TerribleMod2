### __Special Features__

**Transmutation Table**

![](https://media.forgecdn.net/attachments/description/null/description_569f5f27-67bf-486d-8f3d-7622f600d74f.gif)

The Transmutation Table is a new GUI that allows the player to place items inside it to gain new items that cannot be obtained from other sources, these items can be vanilla or modded!

Additionally to go along with this feature is a gamerule that enables a challenge run to disable them, the mod has been specificly designed to be able to be beaten without this feature, so have fun!
